시안 플로우 시안

UI 작업을 할 때 "시안부터" 그려서 옆 패널에 띄우고, 다듬은 다음 구현으로 넘어가는 흐름입니다. 진행 순서는 mockup 스킬이 정하고, 패널을 다루는 일은 preview 툴이 맡습니다.

① 요청"시안부터" / UI 변경
→
② 바뀌는 점 정리상태 A/B/C 나누기
→
③ 시안 작성design/mockups/<주제>/
→
④ 옆 패널에 띄우기preview open · 자동 새로고침
→
⑤ 피드백 ↔ 수정채팅 또는 패널에서 직접 찍기
→
⑥ 승인 → 구현캡처 PNG 보관 · 임시 데이터 정리

A.시안이 옆 패널에 뜸

스킬이 자동으로 켜지고, 시안 파일을 쓰자마자 패널에 탭이 열립니다. 이후 시안 파일을 고칠 때마다 패널이 스스로 새로고침되므로 따로 다시 열 필요가 없습니다.

설정 화면 연결 탭 시안부터 보여줘
● 스킬 mockup 적용
✎ 파일 작성 design/mockups/conn-tab/index.html
▣ preview open conn-tab/index.html

분홍 테두리는 preview annotate로 붙인 표시입니다. 시안 HTML 안에 직접 그려 넣는 게 아니라 패널 위에 덧씌우는 것이라, 시안 파일은 깨끗하게 유지됩니다.

B.방향이 다른 시안 비교

방향이 갈릴 때는 시안 2~3개를 나란히 놓고 보여 줍니다. 아래 칩을 누르면 그 시안으로 정해지고, 다른 시안 탭은 닫힙니다.

C.패널에서 찍어서 말하기 2단계

"✎ 찍어서 말하기"를 켜고 시안의 요소를 누르면 짧은 코멘트 창이 뜹니다. 보내면 그 요소(위치와 선택자)가 다음 메시지에 첨부되어, "이거 말하는 거야"를 따로 설명할 필요가 없어집니다.
