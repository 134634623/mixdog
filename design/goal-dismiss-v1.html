완료된 Goal 닫기 · 시안 v1

끝난(완료·중지된) Goal 표시를 화면에서 치우는 버튼 위치입니다. 진행 중인 Goal에는 나오지 않습니다. 실제 앱의 어두운 테마 색과 크기를 그대로 썼습니다.

파란 점선 = 새로 추가되는 버튼

지금 — 닫을 방법이 없음

A안 — 펼친 창 아래에 '목표 닫기'

진행 중일 때 일시정지·수정·중단 버튼이 있던 자리입니다. 끝난 셸 작업의 '닫기'와 같은 방식입니다. 접힌 상태에서는 한 번 펼친 뒤 누릅니다(두 번 클릭).

B안 — A안 + 접힌 표시줄 끝에 × 추천

접힌 상태에서도 바로 한 번에 닫습니다. 펼친 창에는 A안 버튼이 그대로 있습니다. 끝난 Goal에만 ×가 붙어서, 진행 중인 표시줄은 지금과 같습니다.

동작 (A·B 공통)

  • 누르면 표시가 바로 사라집니다. 이미 끝난 Goal이라 확인 창은 띄우지 않습니다.
  • 기록은 지우지 않고 보관합니다. 다음 메시지를 보냈을 때와 같은 처리입니다.
  • 진행 중·일시정지·답변 대기인 Goal에는 나오지 않습니다. 그때는 지금처럼 일시정지·수정·중단입니다.
  • 펼친 창 오른쪽 위 ×는 지금처럼 창만 접습니다.
  • PC와 휴대폰이 같은 화면 코드라 둘 다 적용됩니다.
