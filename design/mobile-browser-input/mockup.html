참고
  • 입력줄은 폰 화면에서만 보입니다. 폰 키보드의 Enter·지우기 버튼은 페이지로 그대로 전달됩니다. PC에서는 지금처럼 페이지에 바로 입력합니다.
  • 1안은 폰 화면 쪽만 수정하면 됩니다. 2안은 PC가 "지금 선택된 곳이 입력칸인지"를 폰에 알려주는 기능이 추가로 필요합니다.
  • 2안에서 입력줄 왼쪽 라벨(예: "검색창")은 지금 어느 칸에 입력 중인지 보여줍니다. 비밀번호 칸이면 입력줄도 가림 처리합니다.
  • 한글 조합 중인 글자도 실시간으로 페이지에 반영되는 것을 목표로 합니다.
