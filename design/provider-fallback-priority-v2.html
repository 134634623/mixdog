동작 규칙

설정 위치모든 에이전트(Lead 포함)의 모델 시트에 "예비 모델" 한 줄. Lead 전용 창 없음.
Lead 기본값워크플로우의 Lead = 기본값. 입력창 모델 선택 = 이 세션만 덮어쓰기(예비 설정은 Lead 것을 그대로 따름).
예비 모드자동(기본): Providers 순서대로 다음 프로바이더의 같은 급 모델 · 직접 지정: 이 에이전트만의 목록 · 없음: 멈추고 알림.
전환 조건현재 프로바이더의 사용 가능한 계정이 모두 소진됐을 때만. 같은 프로바이더 안 계정 순번이 먼저. 일반 429는 기존 재시도.
소진 시에이전트별 "물어보기 / 자동 전환" (기본: Lead는 물어보기, 하위 에이전트는 자동 전환 — 백그라운드에서 사람이 못 볼 수 있으므로).
일시중지Providers 팝업에서 계정·프로바이더 단위. 중지 항목은 자동 예비와 계정 순번에서 빠지고, 직접 지정 목록에선 건너뜀.
범위·복귀전환은 그 세션/작업에만. 리셋 이후 다음 턴 시작 때 원래 모델로 복귀. 대화 기록·도구 결과는 넘기고 모델 내부 추론은 넘기지 않음.
