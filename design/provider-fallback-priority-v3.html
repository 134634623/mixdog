동작 규칙

카드가 뜨는 때현재 프로바이더의 사용 가능한 계정이 모두 소진됐을 때만. 같은 프로바이더 안 계정 자동 순번은 지금 그대로 먼저 동작.
이어서고른 모델로 멈춘 턴을 그대로 이어감. 대화 기록·도구 결과는 넘기고, 모델 내부 추론 기록은 넘기지 않음. 새 세션·inherit 불필요.
유지 범위그 세션에만 적용, 기본 모델 설정은 그대로. 세션 안에서 다시 소진되면 지난번 모델이 첫 버튼(B).
복귀자동으로 바꾸지 않음. 리셋 후 턴이 끝나면 한 번 제안(E), 언제든 입력창 칩에서 직접 복귀(D).
하위 에이전트카드 없음. Worker 등은 지금처럼 실패를 보고하고 Lead가 다른 에이전트로 다시 맡김.
일시중지Providers ⋯ 메뉴에서 프로바이더·계정 단위. "재개할 때까지 / 다음 리셋까지" 두 가지만.
