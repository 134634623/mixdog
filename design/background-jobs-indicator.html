백그라운드 작업 대기·표시 시안

피드백: “백그라운드 잡을 기다리는데도 ‘답변 완료’가 떠서 헷갈린다 / 잡이 도는지 표시가 되면 좋겠다”

현재: 셸 1개 · 에이전트 1개 실행 중

1. 턴이 끝났을 때 문구

마지막 응답 아래 줄만 바뀝니다. 작업이 끝나 결과가 돌아오면 이어지는 응답에서 평소처럼 “완료”가 뜹니다.

현재 그냥 완료 표시

작업이 아직 돌아도 체크 + “작업 완료”

빌드를 백그라운드로 돌려 두었습니다. 끝나면 결과를 확인하겠습니다.
shell npm run build background
✓작업 완료 · 14초

A 대기 상태로 대체

체크 대신 스피너, 문구 자체를 “대기 중”으로. 끝나면 체크로 바뀜

빌드를 백그라운드로 돌려 두었습니다. 끝나면 결과를 확인하겠습니다.
shell npm run build background
백그라운드 작업 2개 대기 중 · 셸 1 · 에이전트 1
✓작업 완료 · 14초

B 완료 + 꼬리표

이번 응답은 끝났다고 두고, 옆에 실행 중 꼬리표만 붙임

빌드를 백그라운드로 돌려 두었습니다. 끝나면 결과를 확인하겠습니다.
shell npm run build background
✓작업 완료 · 14초 백그라운드 2개 실행 중

2. 실행 중인 작업 표시 위치

셸 + 에이전트 개수를 합쳐 보여 주고, 누르면 목록이 열립니다. 작업이 없으면 사라집니다. (칩을 눌러 보세요)
