2. 칸별 모습

칸모습규칙
Goal 결제 모듈을 새 API로 이전3/512m 파란 진행률 막대, 진행 수, 경과 시간을 표시합니다. 시간은 분 단위로 쓰고(1시간이 넘으면 "1h 05m"), 초는 펼친 패널에서만 보입니다. 제목은 혼자 있거나 화면이 넓을 때만 보입니다.
Goal · 완료 5/532m   3/518m 알림 없이 칸 안에서만 바뀝니다. 끝나면 초록 체크로, 멈추면 회색 정지 표시로 바뀌고, 다음 메시지를 보낼 때 사라집니다.
에이전트 에이전트 7작업 중 4 · 대기 2 · 승인 1 상태별 개수를 보여 주고, 0인 상태는 생략합니다. 승인 대기만 노란색입니다.
에이전트 · 모두 대기 에이전트 2대기 2 돌고 있는 에이전트가 없으면 점이 회색으로 멈춥니다.
셸 셸npm test -- payment   셸npm test -- payment +2 가장 최근 명령을 보여 주고, 여러 개면 뒤에 "+N"을 붙입니다.
파일 4개 파일 변경 +82−17   client.ts 변경 +12−3 문장형으로 씁니다. 파일이 하나면 파일 이름을 보여 줍니다. +와 − 사이에는 구분선 없이 띄어쓰기만 둡니다.
모델 불일치 Claude Opus 5.5로 계속 노란 점 하나에 글자는 회색으로 둡니다.

5. 공통 규칙

  • 크기: 알약 34px, 칸 26px, 글자 14px 굵기 500(컴포저 모델 이름과 같은 크기 · 라벨 굵기), 보조 글자는 굵기 400 회색, 패널 제목은 14px 굵기 600
  • 테두리: 은은한 테두리와 위쪽 하이라이트, 부드러운 그림자, 패널 모서리 18px
  • 구분선: 칸과 칸 사이에만 둡니다. 칸 안(+/− 사이, 이름 앞)에는 넣지 않습니다
  • 색: 진행 중은 파란 점, 진행률은 파란 막대, 주의·승인은 노란색, 대기는 회색 점. 색은 점과 막대, 승인 표시에만 씁니다
  • 알림: 백그라운드 작업 완료 알림은 띄우지 않습니다. 화면이 들썩이는 것을 막기 위해서입니다
  • 흔들림 방지: 칸 안 시간은 분 단위로만 바뀝니다. 숫자 자리에는 최소 너비를 둬서 알약 길이가 자주 변하지 않게 합니다
  • 클릭: 에이전트 칸을 누르면 에이전트 탭이, 셸 칸을 누르면 셸 탭이, Goal 칸을 누르면 Goal 작업 목록이 열립니다
  • 승인 개수: 승인 카드와 같은 데이터를 봅니다. 승인 대기를 정확히 구분할 수 없으면 "대기"로 합칩니다
  • 테마 · 기기: 라이트 테마와 휴대폰 화면도 같은 규칙으로 맞춥니다
  • 빈 상태: 표시할 게 없으면 아일랜드 자리가 0으로 접힙니다. 나타날 때는 0.18초 동안 부드럽게 펼쳐집니다
