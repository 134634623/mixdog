컨텍스트 슬라이더 · 기본값 맞추기 시안

슬라이더를 직접 움직여 보세요. 기본값 칸(파란 눈금)에 놓으면 퍼센트 계산이 아니라 서버 기본값(500K)이 정확히 적용됩니다.

  • 파란 눈금 + "기본" 라벨: 기본값 칸 위치를 슬라이더 위에 표시합니다. 끌다가 여기 놓으면 정확히 500K입니다.
  • ↺ 500k · 기본 칩: 지금도 있는 "기본값으로 되돌리기" 버튼입니다. 테두리와 아이콘을 넣어 눌리는 버튼처럼 보이게만 바꿉니다. 누르면 저장된 퍼센트가 지워지고, 이후 서버 기본값이 바뀌면 자동으로 따라갑니다.
  • 기본값 칸에 있을 때: 칩 대신 상단 숫자 옆에 파란색 "· 기본"이 표시됩니다.
  • 팝업이나 숫자 직접 입력은 넣지 않습니다.
