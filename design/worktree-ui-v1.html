③ 세션 도중 worktree로 옮기기

대화는 그대로 이어집니다. 커밋 안 한 변경은 같이 옮기는 게 기본이고, 원래 폴더의 변경은 지우지 않고 보관합니다. 실행 중인 작업이 있으면 먼저 멈춰야 합니다.

참고: Codex "Where should the new conversation run?" + 실행 중 작업·터미널 있으면 거부 · opencode 변경 같이 옮기기(moveChanges) · Hermes "Terminal and file tools now operate in the worktree"

④ 합치기 / 지우기

합치기 전에 충돌을 미리 검사해서, 충돌이 있으면 원래 폴더를 건드리지 않습니다. 지우기는 남은 변경을 구체적으로 보여주고, 있으면 강제로 지우기만 가능합니다.

참고: Paseo "Merge locally" + 보관 경고 목록("Uncommitted changes", 안 푸시한 커밋) · Crystal "Merge to main" · Orca·Zed·Roo "Force Delete"
