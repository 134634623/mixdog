동작 규칙

전환 조건현재 프로바이더의 사용 가능한 계정이 모두 소진됐을 때만. 일반 429·일시 오류는 기존 재시도. 같은 프로바이더 안 계정 순번은 지금처럼 먼저 소진.
순서Providers 팝업 순서 = 예비 순서. 1번이 Lead 기본 경로. 설정 화면의 예비 목록과 같은 값을 공유.
일시중지계정/프로바이더 단위. 중지 항목은 순번·예비 목록에서 제외. 현재 쓰는 프로바이더를 중지하면 다음 턴부터 예비로 넘어감(진행 중인 턴은 끝까지).
전환 범위이 세션에만 적용, 기본 설정은 그대로. 대화 기록·도구 결과는 그대로 넘기고, 모델 내부 추론 기록은 넘기지 않음.
짧은 대기리셋이 설정값(기본 10분) 이내면 전환 대신 대기 후 자동 재개.
복귀기본 모델 리셋 이후 다음 턴 시작 시 복귀(턴 중간엔 바꾸지 않음). 칩 팝업에서 "지금 복귀"/"이 세션은 계속" 선택 가능.
하위 에이전트기본 꺼짐. 켜면 Worker·Reviewer도 같은 예비 목록을 사용.
