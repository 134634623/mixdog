화면 조작 준비 v1 · 번거롭지 않은 권한 안내

원칙은 "필요할 때만, 한 번만, 버튼 하나로"입니다. 준비가 다 돼 있으면 아무것도 보이지 않고, 처음 실제로 필요한 순간에 대화 안에서 카드 하나로 묻습니다. 앱이 대신 고칠 수 있는 건 버튼 하나로 끝내고, 돌아오면 저절로 다시 확인해 하던 작업을 이어 갑니다. 아래 화면은 Ubuntu 24.04 GNOME(Wayland)을 기준으로 그렸고, 같은 틀을 맥·윈도우에도 씁니다.

언제 묻나앱 시작·설정 열 때 묻지 않음. 에이전트가 처음 실제로 필요한 동작을 할 때 한 번.
Claude Code · oh-my-pi · Cherry Studio
무엇을 보여 주나운영체제 권한 이름이 아니라 할 수 있는 일 단위(보기·읽기·창 전환·마우스/키보드). 초록 배지 하나로 뭉뚱그리지 않음.
cua · Hermes
어떻게 고치나항상 다음 행동 한 개. 명령어는 "자세히" 안에만. 확인만 할 때는 절대 시스템 창을 띄우지 않음.

3. 창 전환 도우미가 필요할 때 (GNOME만)

GNOME은 다른 앱의 창 목록·전환을 기본으로 열어 주지 않아서 작은 확장이 필요합니다. Mixdog 안에 넣어 두고 버튼 하나로 설치합니다. 설치는 GNOME이 직접 확인을 받습니다.

W1대화 안 카드

GNOME에서 창을 찾고, 내용을 읽고, 바꾸는 작은 확장을 설치해요. 설치 후 한 번 로그아웃하면 적용돼요.

그때까지는 화면을 보면서 할 수 있는 일만 할게요. 나중에 로그아웃했다가 다시 로그인하면 저절로 켜져요.

지금 로그아웃나중에

GNOME은 새 확장을 다음 로그인 때 읽습니다. "지금 로그아웃"은 저장 안 한 작업이 있을 수 있어 기본 버튼으로 두지 않습니다.
