브랜치 칩 시안 v3

worktree 칩을 따로 두지 않고, 스웜 다음에 현재 브랜치를 보여주는 칩 하나만 둡니다. 별도 폴더(worktree)는 브랜치 목록 맨 위의 스위치 하나로 켭니다. "worktree"라는 단어는 칩과 메뉴에 나오지 않고 설정과 툴팁에만 남습니다.

① 새 작업

칩은 현재 브랜치(⎇ main)를 보여줍니다. 열면 브랜치 목록이 나오고, 맨 위 "별도 폴더에서 작업" 스위치를 켜면 고른 브랜치를 기준으로 새 브랜치와 폴더를 자동으로 만듭니다. 끄면 지금처럼 프로젝트 폴더에서 해당 브랜치를 체크아웃합니다.

참고: VS Code 브랜치 드롭다운 앞의 "New Worktree" 체크 · Zed "{브랜치} 기준으로 새 worktree 만들기" · Orca 다른 worktree가 쓰는 브랜치 구분 · lobe-chat "In worktree {이름}" 표시

③ 소스 컨트롤 패널의 기존 브랜치 선택기
