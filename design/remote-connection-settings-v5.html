수정 대상 네 가지: ① 모두 연결 해제 위치 ② 코드 위치 ③ 코드가 늦게 뜸 ④ 정렬·간격. 왼쪽은 지금 화면, 오른쪽은 수정안입니다.

웹 탭: 코드를 설명 순서대로 배치

지금은 코드가 왼쪽 맨 앞에 있고, 설명은 오른쪽에서 "왼쪽 코드를 입력하세요"라고 되돌아가게 합니다. 수정안은 위에서 아래로 1 주소 → 2 코드 순서로 읽힙니다.

다른 PC 탭: 두 칸의 줄을 맞춤

지금은 두 카드의 설명 문구가 맨 아래에 있어 길이에 따라 높이가 달라지고, 왼쪽은 타이머 줄, 오른쪽은 버튼 줄이라 모양이 어긋납니다. 수정안은 한 카드 안에 두 칸을 두고 제목, 설명, 64px 칸, 36px 줄을 같은 높이에 맞춥니다.

모바일 탭: QR과 코드를 같은 자리에

QR은 지금처럼 왼쪽, 설명은 오른쪽입니다. "코드로 연결"을 누르면 QR 자리(200px)에 같은 코드 블록이 들어가, 화면이 흔들리지 않습니다. 간격만 다른 탭과 맞춥니다.

코드가 늦게 뜨는 문제

원인: 화면이 열리면 코드를 한 번 요청하고, 연결 서버는 1초 안에 코드를 줍니다. 그런데 화면이 결과를 다시 확인하는 간격이 8초(CODE_POLL_MS = 8_000)라서, 코드를 받아 두고도 최대 8초 늦게 보입니다. "새 코드"를 눌렀을 때도 같습니다.
