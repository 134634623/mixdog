SSH 서버 연결 v4 · 실제 앱 스타일

앱의 실제 스타일시트(desktop.css, styles.css, settings.css)를 불러와 그렸습니다. 대화상자는 ConnDialog, 목록 줄은 ConnRow, 복사 줄은 AddressRow, 번호 단계는 conn-steps, 제목줄 메뉴는 RemotePcSwitcher와 같은 마크업입니다. 문구는 기존 연결 화면의 말투(“연결할 기기 종류를 고르세요.”, “직접 요청한 경우에만 허용하세요.”)에 맞췄습니다.

점선 테두리는 새로 더하는 부분입니다. 흐름: 주소 입력 → [연결] → 진행(필요할 때만 확인·안내 화면) → 서버 창

1. 입구

기존 두 입구에 한 줄씩 더합니다.

2. 주소 입력

입력칸 하나뿐입니다. 이름 칸이나 고급 설정은 두지 않습니다. 이름은 주소로 정해지고, 포트·키는 주소(user@서버:포트)와 이 PC의 SSH 설정을 따릅니다.

3. 연결

[연결]을 누르면 같은 대화상자의 내용이 진행 단계로 바뀝니다(“기기 연결”이 요청 승인 화면으로 바뀌는 것과 같은 방식). 확인이나 조치가 필요할 때만 그 화면으로 바뀌고, 해결되면 이어서 진행합니다.

4. 서버 창

다른 PC를 열 때처럼 서버 전용 창이 열립니다. 제목줄 왼쪽 이름표가 서버 이름이고, 창 안은 지금 앱과 같습니다. 따로 뜨는 첫 화면은 없습니다. 바뀌는 곳은 [프로젝트 추가]를 눌렀을 때 뜨는 폴더 선택 창 하나뿐입니다.
