위쪽 띠는 에이전트 상태 머신(FSM)입니다. 상자는 코드에 이미 있는 상태(desktopAgentActivityState: 대기열 · 실행 중 · 승인 대기 중 · 작업 대기 · 완료/대기 중)이고, 각 에이전트가 지금 상태 상자 안에 칩으로 들어가 있습니다. 상태가 바뀌면 칩이 화살표를 따라 옮겨 갑니다. 취소됨/취소 미확인은 해당할 때만 오른쪽 끝에 나타납니다. 아래 그래프와 상단 숫자, 승인 카드는 전부 지금 에이전트 목록 데이터(awaitingUser: 'approval' 포함)만으로 그릴 수 있습니다. 점선 「+ 추가 데이터」 표시가 붙은 “지금 실행 중인 도구” 한 줄만 새 데이터가 필요합니다(현재 에이전트 목록에는 도구 이름이 없음). 승인 카드의 명령 문구도 같은 이유로 런타임에서 넘겨줘야 합니다. 워크플로(Default·Headless)는 지침 문서일 뿐 단계 정보가 없어서, 지난 시안처럼 “상담→계획→실행” 단계를 그리려면 런타임에 단계 개념부터 만들어야 합니다 — 그래서 이번엔 실제 존재하는 상태 기계로 바꿨습니다. Goal이 켜진 세션이라면 같은 띠를 Goal 작업 상태(대기 → 진행 중 → 승인 대기 → 완료/제외)로 바꿔 보여주는 탭을 하나 더 둘 수 있습니다.
